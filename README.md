# ניהול פינוי בינוי

עוזר עבודה אישי למחתים דיירים בפרויקטי פינוי־בינוי.
פותח את הדייר הנכון לטיפול בכל רגע נתון, במקום להחזיק בראש את ציר הזמן של עשרות שיחות.

## מה יש כאן

הריפו הזה מכיל **קוד בלבד** — שלושה קבצים סטטיים שמוגשים דרך GitHub Pages:

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה — מסכים, מנוע התעדוף, הקלטה קולית |
| `sw.js` | Service Worker: פתיחה מיידית ועבודה בלי רשת |
| `manifest.json` | הגדרות PWA להתקנה במסך הבית |

## מה אין כאן

**אין בריפו הזה שום מידע.** לא שמות דיירים, לא טלפונים, לא כתובת השרת ולא קוד הגישה.

הנתונים יושבים בגיליון Google פרטי, והאפליקציה ניגשת אליו דרך Apps Script.
כתובת השרת נשמרת מקומית במכשיר בלבד, והגישה מוגנת בקוד אישי.
אפליקציה שנפתחת בלי אלה אינה מחוברת לדבר.

## התקנה בפלאפון

פתח את הכתובת בדפדפן ובחר **הוסף למסך הבית**.

## עדכון גרסה

בכל שינוי בקבצים יש להעלות את מספר הגרסה ב־`sw.js` (`pinui-binui-v1` ← `v2`),
אחרת הדפדפן ימשיך להגיש את הגרסה השמורה במטמון.
