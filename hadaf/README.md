# הדף השבועי של בני עקיבא — תשפ"ז

אפליקציה סטטית (PWA) לתוכנית הדף השבועי: כיתות ז׳ לומדות מסכת תענית,
כיתות ח׳ מסכת מגילה — דף בשבוע, לאורך כל השנה.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה — מסכים, מנוע המצגת, החידה |
| `data.js` | **כל התוכן.** לוח השנה, המוסדות, המצגות והחידות |
| `links.js` | קישורי צורת הדף והחברותא, מיובא מ"יגדיל תורה" |
| `sw.js` | Service Worker — פתיחה מיידית ועבודה בלי רשת |
| `manifest.json` | הגדרות PWA להתקנה במסך הבית |

## עדכון תוכן שבועי

הכול ב-`data.js`. אין צורך לגעת בקוד.

```js
CONTENT['taanit-7'] = {          // taanit או megila, ומספר השבוע (1–36)
  title: 'כותרת הדף',
  slides: [ { k:'שער', h:'כותרת', t:'טקסט' }, ... ]   // עד 10; ריק = לא מוצג
};
QUIZ['taanit-7'] = { q:'השאלה', a:['א','ב','ג','ד'], correct:1 };
```

## עדכון גרסה — חובה בכל שינוי

יש להעלות את `CACHE_NAME` ב-`sw.js` (`hadaf-v1` ← `hadaf-v2`),
אחרת מכשירים ימשיכו להגיש את הגרסה השמורה במטמון.
מומלץ לעדכן גם את `APP_VERSION` ב-`index.html` — הוא רק מוצג בתחתית.

המנגנון זהה לזה של "יגדיל תורה": ה-Service Worker החדש **ממתין**
ולא נכנס לתוקף מעצמו. מוצג פס ירוק "גרסה חדשה זמינה", ורק לחיצה
עליו מפעילה אותו. כך תלמיד באמצע חידה לא נקטע.

## קישור לפי מוסד

`?m=<code>` משייך את מי שנכנס למוסד שלו מראש — למשל `?m=raanana`.
הקודים נמצאים ב-`INSTITUTIONS` בתוך `data.js`.

## מה עדיין לא מחובר

- `API` — כתובת ה-Apps Script. עד שתוגדר, תשובות החידה נשמרות
  בתור המקומי ונשלחות כשיהיה חיבור.
- אימות קוד הכניסה של רכז/מנהל.
- **קישורי צורת הדף והחברותא של מסכת תענית** — במסד של "יגדיל תורה"
  יש 31 דפים של מגילה בלבד; לתענית אין אף אחד.
- תמונות הגמרות במסך הרכישה.
